# LINE 官方帳號客戶管理系統

替**機場接送、包車、租車自駕**業者的 LINE 官方帳號做的小型 CRM，讓客服每天打開就知道「今天要派哪台車、要提醒誰、該說什麼」。支援**多品牌**：每個品牌各自一個 LINE 官方帳號，同一組客服在同一個後台管理全部品牌。

## 功能

| 功能 | 說明 |
| --- | --- |
| **多品牌** | 每個品牌有自己的 LINE 金鑰、Webhook 網址、代表色、匯款資訊。客戶、訂單、訊息、提醒都歸屬於品牌；給客戶的訊息自動帶入該品牌的名稱與匯款帳號，並從該品牌的官方帳號發出。後台左上角可切換「全部品牌」或單一品牌，每位客戶都標示品牌色標籤。 |
| **自動收集客戶資料** | 客戶加好友、傳訊息時，自動建立客戶檔（LINE 名稱、大頭貼、userId）；封鎖時自動標記。客服可補上真實姓名、電話、Email、生日、性別、地址、標籤、備註。認證／進階帳號可一鍵「同步 LINE 好友」。 |
| **全站搜尋** | 頂端搜尋框可找客戶（姓名、LINE 名稱、電話、標籤、備註）、訂單（航班、上下車地點、車型、備註、`#訂單號`）與對話內容；電話不論有無「-」、空格、+886 都找得到。可加用車日期範圍，只選日期就列出那段期間的所有行程。跟著左上角品牌篩選。 |
| **合併重複客戶** | 同一人被建立兩次（例如先匯入舊資料、後來才在 LINE 傳訊息）時，客戶資料會提示「可能是同一個人」，一鍵合併：訂單、對話、提醒紀錄搬到同一筆，空白欄位互補，標籤與備註合併，LINE 連結保留。「客戶」頁的「找重複客戶」可一次列出同品牌中電話或姓名相同的客戶。 |
| **匯入舊資料** | 「客戶」頁按「匯入舊資料」上傳 CSV：可直接匯入首席後台「匯出全部訂單 CSV」、Airtable 匯出的 CSV，或照範本填寫的 Excel／Google 試算表。欄位自動對應（可手動調整），先預覽再匯入；依電話、姓名、LINE 名稱對應現有客戶，過去的行程標為已完成、不會催款，重複匯入不會重複建立。 |
| **行程訂單** | 每筆訂單記錄服務類型（機場接送／包車／租車自駕）、用車日與時間、航班、上車／取車地點、目的地／還車地點、結束／還車日、車型或內容。狀態：待付款 → 已付款 → 已派車 → 已完成。航班或時間異動時，在客戶資料按「編輯」修改。新訂單自動帶入匯款期限：下單後 3 天，但最晚在用車前一天。 |
| **即將用車** | 「訂單」頁預設列出今天起 7 天內的行程，依用車時間排序，方便排車。 |
| **行程確認** | 用車前一天，關懷清單會列出「明天用車，請傳行程確認」，一鍵推播時間、航班、地點給客戶，請客戶有異動就回覆。可開啟每日自動傳送（每筆訂單只傳一次）。當天還沒派車的行程會列為緊急，按「標記已派車」即可。 |
| **消費紀錄與總覽** | 每位客戶的完整訂單紀錄，以及總覽：客戶類型、訂單數、累積消費、平均客單價、首次／最近用車、常用服務、回訪週期、預計回訪日。 |
| **回訪追蹤** | 「回訪」頁列出所有用過車的客戶，依預計回訪日排序，可篩選「可邀請了／7 天內／沉睡客／全部」，一鍵發送回訪邀請。 |
| **匯款提醒** | 一鍵推播匯款提醒（含金額、期限、匯款帳號）。可開啟每日自動提醒：明天到期、今天到期、已逾期，每筆訂單一天最多一次、總共最多 3 次。 |
| **客戶回報匯款** | 客戶在 LINE 打「已匯款 末五碼12345」或傳截圖，系統自動記到該筆訂單，列入清單請客服核對（預設不自動回覆客人；設 `AUTO_REPLY=true` 才會回覆「已收到匯款通知」）。確認入帳時可順便傳「已收到款項」通知。 |
| **今日關懷清單** | 依優先度列出今天要處理的客戶（見下表），每天定時推播摘要到客服的 LINE。 |
| **回訪邀請** | 依每位客戶過去的用車間隔自動推算回訪週期（或手動設定），時間到了提醒客服邀請再次預約。訊息依客戶類型與上次的服務換說法：首次客先問這趟行程順不順利，回頭客問最近有沒有出國或出遊計畫，沉睡客只問候不催單（參考 ThinkWithBlack MK-390 第一次回購促進計畫）。邀請過後，一個回訪週期內不會再列入清單。 |
| **客戶自助查訂單** | 設 `AUTO_REPLY=true` 時，客戶在 LINE 輸入「查訂單」會自動回覆最近 5 筆訂單狀態（預設關閉）。 |
| **匯出** | 客戶名單（含消費統計、回訪日）與訂單（含行程資料）都可匯出 CSV（Excel 可直接開）。 |

### 今日關懷清單的規則

| 優先度 | 狀況 | 建議動作 |
| --- | --- | --- |
| 🔴 緊急 | 客戶已回報匯款 | 核對入帳 |
| 🔴 緊急 | 匯款已逾期 / 今天到期 | 發送匯款提醒 |
| 🔴 緊急 | 客戶傳訊息還沒處理 | 回覆 |
| 🔴 緊急 | 今天用車，還沒派車 | 標記已派車 |
| 🟠 今日 | 明天用車，還沒傳行程確認 | 發送行程確認 |
| 🟠 今日 | 匯款明天到期 | 發送匯款提醒 |
| 🟠 今日 | 客服排定今天聯絡（「下次聯絡日」） | 關心 |
| 🟠 今日 | 距上次用車已超過回訪週期 | 發送回訪邀請 |
| 🟠 今日 | 今天生日 | 發送生日祝福 |
| 🔵 有空時 | 新好友 7 天內尚未下單 | 發送關心問候 |

每位客戶卡片上都會顯示消費摘要（類型、訂單數、累積消費、客單價、最近用了什麼服務、電話），客服不用點進去就能直接聊。問候在 3 天內、回訪邀請在一個回訪週期內不會重複出現；按「延後 3 天」可暫時從清單移除。

### 客戶類型與回訪週期

- 日期都以**用車日**計算（沒填用車日才用下單日），提前預約的行程要等用完車才開始算。
- **回訪週期**：手動設定 → 否則用過去用車的平均間隔 → 只用過一次則用 `DEFAULT_REORDER_DAYS`（預設 90 天）。
- **預計回訪日** = 最近用車日 + 回訪週期。
- **客戶類型**：尚未下單／首次客（1 筆）／回頭客（2–4 筆）／忠實客（5 筆以上）／沉睡客（超過 2 倍回訪週期且 60 天以上沒用車）。

## 安裝

需要 **Node.js 22.13 以上**，不需要安裝其他套件（資料存在內建 SQLite 檔案）。

```bash
cp .env.example .env    # 填入後台密碼等
npm start               # 啟動於 http://localhost:3000
npm run demo            # （選用）放入示範資料試用
npm test                # 執行測試
```

後台登入帳號 `admin`，密碼為 `.env` 中的 `ADMIN_PASSWORD`。

### 串接 LINE 官方帳號（每個品牌做一次）

1. 把系統部署到有 HTTPS 的網址。**建議用 Render，已附設定檔，照 [docs/deploy-render.md](docs/deploy-render.md) 一步一步做即可**；也可用 Railway、Fly.io、自己的主機＋Cloudflare Tunnel，本機測試可用 ngrok。
2. 後台「品牌」頁 →「新增品牌」：填品牌名稱、網址代號（英數字，如 `chicken`）、代表色、匯款資訊。
3. 到 [LINE Developers](https://developers.line.biz/console/) 找到該品牌官方帳號的 **Messaging API channel**，把 **Channel secret** 與 **Channel access token（長期）** 貼到品牌設定（金鑰不會在後台再顯示，留空表示不修改）。
4. 在同一個 Messaging API 設定頁：**Webhook URL** 填品牌頁顯示的 `https://你的網址/webhook/<代號>`，按 Verify，並開啟 **Use webhook**。
5. 在 [LINE Official Account Manager](https://manager.line.biz/) → 回應設定：可同時開啟「聊天」與「Webhook」，客服照常在官方帳號後台聊天，本系統負責記錄與提醒。

> 從舊版（單一品牌）升級：第一次啟動時，原有客戶會自動歸到「預設品牌」（代號 `default`），`.env` 的 LINE 金鑰與 `SHOP_NAME`、`BANK_INFO` 會帶入這個品牌，舊的 Webhook 網址 `/webhook` 照常可用。

### 讓客服每天收到清單

1. 客服用自己的 LINE 加**任一個**品牌的官方帳號好友並傳一則訊息。
2. 在後台「客戶」找到這位客服，打開資料按「設為客服」（客服本身不會出現在關懷清單裡）。
3. 每天 `DAILY_REPORT_HOUR` 點（預設早上 9 點，台灣時間）會由那個品牌的官方帳號收到**全部品牌**的摘要，依品牌分段，例如：

```
【今日關懷清單 2026-10-13】共 9 位
🔴緊急 🟠今日 🔵有空時

━━ 安心機場接送（2）
🔴 Jason：客戶已回報匯款，請核對入帳、有訊息尚未處理（訂單 1 筆，累積 NT$0，最近：機場接送 接機 7 人座）
🟠 王小美：明天用車，請傳行程確認、今天生日 🎂（訂單 4 筆，累積 NT$4800，最近：機場接送 送機 5 人座）

━━ 自在租車（4）
🔴 林先生：今天用車，尚未派車（訂單 1 筆，累積 NT$4800，最近：租車自駕 Toyota Altis）
🟠 Vivi：排定今天聯絡、可邀請再次預約（訂單 1 筆，累積 NT$3600，最近：租車自駕 Honda CR-V）
…
```

設定 `PUBLIC_URL=https://你的網址` 時，摘要會附上後台連結。

## 注意事項

- **訊息額度**：回覆客戶（查訂單、匯款回報的自動回覆）不計費；**推播（匯款提醒、行程確認、回訪邀請、每日摘要）會消耗官方帳號每月免費訊息則數**，自動提醒預設關閉，請依方案斟酌開啟。
- **從舊版升級**：第一次啟動時會自動在訂單表加上行程欄位，舊訂單照常顯示（沒有用車日的以下單日計算）。
- **同一位客人加了多個品牌**：LINE 給每個官方帳號的 userId 可能不同，系統會把這位客人在各品牌的資料分開記錄（各品牌的訂單紀錄、回訪週期互不影響）。
- **既有好友**：LINE 只會在好友互動（加好友、傳訊息）時把資料送到 webhook。一般帳號的既有好友要等他們傳訊息後才會出現；認證／進階帳號可在「品牌」頁按該品牌的「同步好友」一次匯入。
- **客服在官方帳號後台回覆的訊息**不會傳到本系統，回覆後請在清單按「標記已回覆」。
- **個資與備份**：資料庫（`data/crm.db`，Render 上為 `/var/data/crm.db`）含客戶個資，請設定強密碼、使用 HTTPS。後台「品牌」頁右上角可「下載備份」完整資料庫，請定期下載保存。

## 專案結構

```
src/
  server.js     HTTP 伺服器、後台 API、Webhook 入口
  webhook.js    LINE 事件處理：建檔、記錄訊息、匯款回報、查訂單
  focus.js      今日關懷清單規則（含派車、行程確認）
  profile.js    消費統計、客戶分類、回訪名單
  reminders.js  訊息範本、推播、自動提醒、每日排程
  db.js         SQLite 資料表與存取
  line.js       LINE Messaging API 與簽章驗證
public/         客服後台（單頁網頁）
scripts/        示範資料
test/           測試
```
