# LINE 官方帳號客戶管理系統

替 LINE 官方帳號做的小型 CRM，讓客服每天打開就知道「今天要關心誰、為什麼、該說什麼」。

## 功能

| 功能 | 說明 |
| --- | --- |
| **自動收集客戶資料** | 客戶加好友、傳訊息時，自動建立客戶檔（LINE 名稱、大頭貼、userId）；封鎖時自動標記。客服可補上真實姓名、電話、地址、標籤、備註。認證／進階帳號可一鍵「同步 LINE 好友」。 |
| **訂單追蹤** | 每位客戶的訂單：待匯款 → 已匯款 → 已出貨 → 已完成。新訂單自動帶入匯款期限（預設 3 天）。 |
| **匯款提醒** | 一鍵推播匯款提醒（含金額、期限、匯款帳號）。可開啟每日自動提醒：明天到期、今天到期、已逾期，每筆訂單一天最多一次、總共最多 3 次。 |
| **客戶回報匯款** | 客戶在 LINE 打「已匯款 末五碼12345」或傳截圖，系統自動記到該筆訂單並回覆客戶，列入清單請客服核對。確認入帳時可順便傳「已收到款項」通知。 |
| **今日關懷清單** | 依優先度列出今天要處理的客戶（見下表），每天定時推播摘要到客服的 LINE。 |
| **回購提醒** | 依每位客戶過去的下單間隔自動推算回購週期（或手動設定），時間到了提醒客服邀請下單。 |
| **客戶自助查訂單** | 客戶在 LINE 輸入「查訂單」，自動回覆最近 5 筆訂單狀態。 |
| **匯出** | 客戶名單匯出 CSV（Excel 可直接開）。 |

### 今日關懷清單的規則

| 優先度 | 狀況 | 建議動作 |
| --- | --- | --- |
| 🔴 緊急 | 客戶已回報匯款 | 核對入帳 |
| 🔴 緊急 | 匯款已逾期 / 今天到期 | 發送匯款提醒 |
| 🔴 緊急 | 客戶傳訊息還沒處理 | 回覆 |
| 🟠 今日 | 匯款明天到期 | 發送匯款提醒 |
| 🟠 今日 | 客服排定今天聯絡（「下次聯絡日」） | 關心 |
| 🟠 今日 | 距上次下單已超過回購週期 | 發送回購提醒 |
| 🔵 有空時 | 新好友 7 天內尚未下單 | 發送關心問候 |

提醒過的回購／問候在 3 天內不會重複出現；按「延後 3 天」可暫時從清單移除。

## 安裝

需要 **Node.js 22.13 以上**，不需要安裝其他套件（資料存在內建 SQLite 檔案）。

```bash
cp .env.example .env    # 填入 LINE 金鑰、後台密碼等
npm start               # 啟動於 http://localhost:3000
npm run demo            # （選用）放入示範資料試用
npm test                # 執行測試
```

後台登入帳號 `admin`，密碼為 `.env` 中的 `ADMIN_PASSWORD`。

### 串接 LINE 官方帳號

1. 到 [LINE Developers](https://developers.line.biz/console/) 建立（或選擇官方帳號對應的）**Messaging API channel**。
2. 把 **Channel secret** 與 **Channel access token（長期）** 填進 `.env`。
3. 把系統部署到有 HTTPS 的網址（例如 Render、Railway、Fly.io、自己的主機＋Cloudflare Tunnel，本機測試可用 ngrok）。
4. 在 Messaging API 設定頁：
   - **Webhook URL** 填 `https://你的網址/webhook`，按 Verify，並開啟 **Use webhook**。
5. 在 [LINE Official Account Manager](https://manager.line.biz/) → 回應設定：可同時開啟「聊天」與「Webhook」，客服照常在官方帳號後台聊天，本系統負責記錄與提醒。

### 讓客服每天收到清單

1. 客服用自己的 LINE 加官方帳號好友並傳一則訊息。
2. 在後台「客戶」找到客服本人，複製 `LINE userId`（U 開頭）。
3. 填到 `.env` 的 `STAFF_LINE_USER_IDS`（多位用逗號分隔），重新啟動。
4. 每天 `DAILY_REPORT_HOUR` 點（預設早上 9 點，台灣時間）會收到摘要，例如：

```
【我的小店 今日關懷清單 2026-10-13】共 6 位

■ 緊急（3）
・Jason：客戶已回報匯款，請核對入帳、有訊息尚未處理
・Amy：有訊息尚未處理、新好友尚未下單
・王小美：匯款已逾期 2 天

■ 今日（2）
・陳媽媽：該回購了
・林先生：排定今天聯絡
```

設定 `PUBLIC_URL=https://你的網址` 時，摘要會附上後台連結。

## 注意事項

- **訊息額度**：回覆客戶（查訂單、匯款回報的自動回覆）不計費；**推播（匯款提醒、回購提醒、每日摘要）會消耗官方帳號每月免費訊息則數**，自動提醒預設關閉，請依方案斟酌開啟。
- **既有好友**：LINE 只會在好友互動（加好友、傳訊息）時把資料送到 webhook。一般帳號的既有好友要等他們傳訊息後才會出現；認證／進階帳號可在後台按「同步 LINE 好友」一次匯入。
- **客服在官方帳號後台回覆的訊息**不會傳到本系統，回覆後請在清單按「標記已回覆」。
- **個資**：資料庫（`data/crm.db`）含客戶個資，請設定強密碼、使用 HTTPS，並定期備份這個檔案。

## 專案結構

```
src/
  server.js     HTTP 伺服器、後台 API、Webhook 入口
  webhook.js    LINE 事件處理：建檔、記錄訊息、匯款回報、查訂單
  focus.js      今日關懷清單規則
  reminders.js  訊息範本、推播、自動提醒、每日排程
  db.js         SQLite 資料表與存取
  line.js       LINE Messaging API 與簽章驗證
public/         客服後台（單頁網頁）
scripts/        示範資料
test/           測試
```
